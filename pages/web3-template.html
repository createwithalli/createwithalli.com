What's Under the Hood

This entire dashboard is vanilla HTML/CSS/JS — no React, no bundler. Free to deploy on Cloudflare Pages with a Worker for the price oracle backend.

🔐 Wallet Layer ethers.js v6

EIP-1193 provider. Supports MetaMask, Coinbase Wallet, Rainbow, Rabby, and every EVM-compatible wallet. Loaded via CDN — zero build step.

📊 Price Oracle CoinGecko API

Free tier covers 10,000+ tokens with 60-second resolution. Add your Pro API key to the Cloudflare Worker secret to unlock higher rate limits and historical OHLCV data.

⚡ Backend Cloudflare Worker

Edge-cached price proxy with CORS handling. Deploy free on 300 cities worldwide. Supports CoinGecko API key, custom ETH RPC, and portfolio lookup.

🌐 Hosting Cloudflare Pages

Unlimited free static hosting on Cloudflare's global CDN. Deploy straight from GitHub — zero config, instant HTTPS, custom domain included.

⬡ Home Network Base Chain

Coinbase's L2 — built on the OP Stack. Faster and cheaper than Ethereum mainnet. Where creators are building. My primary chain for on-chain activity.

Deploy Your Own

# 1. Clone or fork createwithalli.com
git clone https://github.com/createwithalli/createwithalli.com

# 2. Deploy the price oracle Worker
wrangler deploy workers/web3-worker.js --name my-web3-worker

# 3. (Optional) Add CoinGecko Pro key
wrangler secret put COINGECKO_API_KEY

# 4. Push to GitHub → auto-deploy via Cloudflare Pages
